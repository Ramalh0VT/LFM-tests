# Local ai tests

The name might be self-explanatory, but just for more clarity, it's a repository where i try to extract the most of local ai into vibe coded/ driven developed applications (where it's tried the most to not make any human adaptations to the code, to test ai limits into coding)

## Setup

Laptop 

CPU: I7-8565U (AI runned on cpu due to the horrific performance that UHD 620 is going to give)

RAM: 8GB 2133Mhz single channel (usage of a technology called zram, since 8gb is very low for running ai) 

OS: Linux mint cinammon

SSD: 256GB from a unknown brand

## Original purpose of this repository

Basically, me trying to get LFM to code in different language types, with the limitation of it's parameters. Since i realised i don't need to stick only to lfm models due to hardware limitations (because apparently my setup can do more than i expected, maybe due to zram usage).
